AI Concepts Used

State Space, Initial State & Goal State

Every cell of the grid is a state. The whole grid is the state space — the set of all configurations the agent can be in. The initial state is the start node (green), the goal state is the goal node (red), and actions / operators are the four moves (up, down, left, right) that transition between adjacent states.

Search Tree & Strategy

Algorithms grow a search tree from the initial state: each expanded node branches into its neighbours (children), while the set of nodes waiting to be expanded is the frontier (teal in the visualizer). The search strategy — how nodes are ordered in the frontier (stack, queue, or priority queue) — is exactly what makes BFS, DFS, UCS, Greedy and A* behave differently.

Uninformed vs Informed Search

Uninformed (blind) search — BFS, DFS, UCS — uses no information about the goal’s location; it explores by structure and cost alone. Informed (heuristic) search — Greedy and A* — uses a heuristic function h(n) that estimates the remaining distance to the goal, guiding the search toward it.

Breadth First Search (BFS)

Expands the frontier with a FIFO queue, exploring all nodes at depth d before depth d+1. It always finds the shallowest path, so with uniform step costs it is optimal. Cost: O(bᵗ) time and space.

Depth First Search (DFS)

Expands the frontier with a LIFO stack, diving deep down one branch before backtracking. It is memory-friendly but not optimal — it may find a long winding path. The parent-pointers we store are what allow reconstruction of the final path after backtracking.

Uniform Cost Search (UCS)

Expands nodes by increasing path cost g(n) using a priority queue. It generalises BFS to weighted edges and is optimal. With equal edge costs it behaves like BFS but explores by accumulated cost rather than depth.

Greedy Best First Search

Expands the node with the smallest evaluation function

f(n) = h(n)

It races toward the goal using only the heuristic, so it is fast but not optimal — it can be fooled by an obstacle that forces a detour.

A* Search

Combines the best of UCS and Greedy with the evaluation function

f(n) = g(n) + h(n)

where g(n) = actual cost from the start to n and h(n) = heuristic estimate from n to the goal. Because Manhattan distance never overestimates (it is admissible), A* is optimal and complete, and it is the most efficient optimal informed search.

Hill Climbing (Local Search)

A local search: it starts at the initial state and repeatedly moves to the neighbour with the best heuristic value, keeping no history — no open list, no backtracking. It can reach the global optimum (the goal, h = 0), but it frequently gets stuck at a local optimum: a state whose neighbours are all worse (or equal), even though the goal lies elsewhere. Because it never reconsiders rejected states, it cannot escape — try it on a grid with a long wall!

Simulated Annealing (Local Search)

Inspired by metallurgy, it adds randomness to escape local optima. A temperature T starts high and cools over time. At each step it samples a random neighbour and computes Δ = h(next) − h(current). Better neighbours (Δ < 0) are always accepted; worse ones are accepted with probability

P(accept) = e−Δ/T

High temperature accepts most moves (exploration); low temperature behaves like hill climbing (exploitation). It may find the goal but is not guaranteed — the visualizer tracks the best state visited.

Evaluation Function

Every best-first algorithm ranks frontier nodes with an evaluation function f(n). UCS uses f = g(n), Greedy uses f = h(n), and A* uses f = g(n) + h(n). The choice of f is the entire difference between these algorithms.

Backtracking & Path Cost

Backtracking is how tree/graph searches recover the solution: once the goal is expanded, we walk parent pointers back to the start to reconstruct the final path. The path cost is the sum of edge costs along that path — here 1 per move, so it equals the path length. Compare BFS/A* (optimal cost) against DFS/Greedy (often higher).
