Case Study: Delivery / Route-Planning Agent

Environment and State Representation

The Environment is a 2D grid representing city streets. It contains a Depot (start point), Delivery Locations (goals), Obstacles (buildings), and Traffic zones (high cost paths).

The State Representation includes the agent's current position (x,y), the number of packages currently carried, and the set of remaining delivery locations.

Search & Optimization

The agent uses the A* Search algorithm to find optimal paths. A* is an informed search that evaluates nodes by `f(n) = g(n) + h(n)`, where `g(n)` is the actual movement cost and `h(n)` is the Manhattan distance to the target.

Constraint Handling (CSP)

The agent is subject to a Capacity Constraint. It can only carry a limited number of packages at one time (e.g., 2). Once its capacity is reached or it runs out of packages, it must return to the Depot to reload before it can continue delivering.

Knowledge-Based Reasoning & Inference

The agent uses Forward Chaining to deduce movement costs based on environmental knowledge (Weather rules):

  • Rule 1: IF Weather=Clear, THEN Movement=Normal.
  • Rule 2: IF Weather=Rain AND Cell=Traffic, THEN Cost=High.
  • Rule 3: IF Weather=Snow, THEN Cost=Extreme (All cells).

These logical inferences dynamically alter the `g(n)` edge weights for the A* search graph.

Decision Making

When multiple delivery locations exist, the agent must decide where to go first. It evaluates the available delivery actions and uses a greedy heuristic (closest Manhattan distance) to select the next optimal destination.
